## 0. 本规范如何使用

文档把内容分为两类：

- **【参考图已确定】**：视觉板上可以明确读出的品牌名称、Logo 方向、色板、字体标识、品牌文案和整体风格。**优先保持一致**。
- **【工程建议值】**：参考图没有精确规定、为了 React/shadcn/ui 与 Tauri 实现而补充的字号、尺寸、状态色、对比度与布局参数。这些是初始建议，可在真实 UI 中微调，不可冒充品牌原稿测量值。

品牌名称的具体大小写始终写为 `MdStudio`（大写 M、S），项目包名和目录可使用 `mdstudio`，不要写成 MDSTUDIO、MD Studio 或 Md studio 作为界面主名称。

## 2. 官方主 Logo 方向（不可擅自重设计）

参考文件：

- 全图：`brand/reference/MdStudio_Brand_Board_Approved.png`
- 标志裁切：`brand/reference/Logo_Mark_Reference_NOT_FINAL.png`
- 组合标志裁切：`brand/reference/Logo_Lockup_Reference_NOT_FINAL.png`

### 2.1 图形语义【参考图已确定】

主图标由三种视觉信息融合：

1. **几何字母 M**：主体为圆角、几何感较强的字母 **M**，使用亮蓝到青蓝的柔和渐变，造型简洁、有厚度但不复杂。
2. **Markdown 文档纸张**：M 后方/右侧融入浅色纸张形态，**右上角有向下折叠的蓝色页角**，形成 Markdown 文件隐喻。
3. **文本插入光标**：在右侧纸面上放置细长的深色 **I 形文本光标**，暗示编辑、光标与创作；这是该图标的重要识别特征。

图形与文档层叠，使用圆角、轻微亮蓝—淡紫渐变。整体方形图标区域搭配白色/极浅色背景。视觉重心保持稳固，避免浮夸立体效果。

### 2.2 字标【参考图已确定】

- 字标文字：**MdStudio**。
- 排列：图形在左、字标在右，水平对齐。
- 字体风格：粗体、现代无衬线、字形稳重，紧凑但不挤压。
- 颜色：首选深海军蓝 `#0F172A`；深色背景下可反白为 `#F8FAFC`。
- **所选首版参考图的主字标是深色字标**，不要把其他备选稿里的渐变字标误认为本次官方规范。

### 2.3 主 Logo 版本【工程建议值】

| 资产 | 用途 | 要求 |
| --- | --- | --- |
| `logo-horizontal-light.svg` | 关于页面、欢迎页、官网浅底 | 左图标 + 深蓝字标 |
| `logo-horizontal-dark.svg` | 深色顶栏/欢迎页 | 左图标 + 浅色字标 |
| `logo-symbol.svg` | 桌面图标母版、工具栏 | 仅图形，不带字标 |
| `logo-symbol-mono-dark.svg` | 单色深色 | 全部图形单色化，保留轮廓可识别 |
| `logo-symbol-mono-light.svg` | 单色浅色 | 反白单色 |
| `app-icon-master.png` | Tauri 图标生成输入 | 透明背景或按图标设计采用极浅底，1024×1024 |

**注意**：上表是未来需要生成的目标资产清单，不表示这些 SVG 已从图中真正恢复。Codex 应将原图作为参考进行矢量复刻，人工比对通过后，才能以 `assets/brand/` 正式命名导出。不要把裁切的低分辨率 PNG 放大冒充矢量源文件。

### 2.4 Logo 使用原则【工程建议值】

- 留白：组合 Logo 周围至少保留图形高度约 `0.25×` 的安全距离。
- 最小尺寸：应用图标需单独检查 16、24、32、64、128、256 px 的可辨认度；小尺寸如光标不清晰，可使用经批准的细节简化版。
- 图标母版：画布正方形，内容居中；桌面圆角蒙版尽量交给操作系统或图标输出规范处理。
- 不可拉伸比例、随意旋转、重新着色、添加描边、夸张投影、增加机器人/笔/山峰/星光等新元素。
- 主品牌优先使用参考图的蓝青—淡紫方向，而非新造的橙红、荧光绿或金色方案。

### 3.1 UI 衍生颜色【工程建议值】

以下颜色用于实际可访问 UI，并**非**原图明确给出的第七、第八品牌主色：

| Token | HEX | 说明 |
| --- | --- | --- |
| `action.blue` | `#2563EB` | 浅底按钮背景 + 白色文字，正常文字对比度约 5.17:1 |
| `action.blueHover` | `#1D4ED8` | 悬停、强调操作，白字对比度约 6.70:1 |
| `text.secondary` | `#64748B` | 次级文字（需结合具体背景检查对比度） |
| `surface.white` | `#FFFFFF` | 文件树、浮层、容器 |
| `dark.canvas` | `#0B1220` | 深色模式背景 |
| `dark.surface` | `#111D30` | 深色模式面板 |
| `dark.border` | `#263247` | 深色模式分隔线 |
| `dark.text` | `#F8FAFC` | 深色模式正文 |

**可访问性警示**：`#3B82F6` 搭配白色文字的对比度约 **3.68:1**，不宜作为普通字号按钮文字的默认配色。品牌蓝可用于大面积标识、边框、图形和选中背景；小字号白字按钮请使用 `#2563EB` 或更深颜色，并做实际对比度测试。

### 3.2 推荐使用比例【工程建议值】

- 约 75–85%：白色 / 暖白 / 极浅灰（留白主体）
- 约 10–18%：深蓝黑 / 文本 / 面板框架
- 约 3–8%：品牌蓝 / 青色 / 淡紫点缀

不需要按像素强制套用比例。以长时间阅读舒适为优先级。

## 4. 字体与排版

### 4.1 品牌字体【参考图已确定】

- 英文视觉字体：**Inter**。
- 视觉语气：Modern · Clean · Professional。

### 4.2 中文与系统回退【工程建议值】

```css
font-family: Inter, -apple-system, BlinkMacSystemFont,
  "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC",
  "Segoe UI", system-ui, sans-serif;
```

- 正文：14–16px；编辑器阅读正文建议 16px，可设置 15–18px。
- 默认行高：1.7 左右（中文长文阅读）；英语技术文档 1.6。
- 标题：H1 32/40px；H2 24/32px；H3 20/28px；正文 16/28px，保持统一节奏。
- 字标：推荐 Inter ExtraBold/Bold；应以最终 SVG 曲线字形为准。
- 等宽代码字体建议：JetBrains Mono / SFMono-Regular / Consolas / monospace（不是参考图强制要求）。
- 不要把 Inter 等专有字体文件无授权打包进产品；通过合法许可或系统字体回退使用。

## 5. 品牌风格与组件规则

### 5.1 视觉关键词【参考图已确定】

**Professional / Minimal / Developer-friendly / Intelligent / Reliable**。整体是高留白、轻量分隔、圆角适中、轻微投影、克制的科技感，而非高饱和赛博霓虹或卡片化管理后台。

### 5.2 组件设计建议【工程建议值】

| 组件 | 建议 |
| --- | --- |
| 页面背景 | `#F8FAFC` 或 `#FFFFFF` |
| 顶部工具栏 | 高 48–56px、浅背景、底部细边框 |
| 左侧文件栏 | 默认宽 220–260px，可调整、可收起 |
| 右侧大纲栏 | 默认宽 200–240px，可调整、可收起 |
| 中央编辑区 | 自适应宽度；Markdown 文章最大宽约 820–900px |
| 文档标签 | 选中态以浅品牌蓝底或底边线突出 |
| 分隔线 | 使用 `#E5E7EB` 或更淡的边界 |
| 圆角 | 控件 6–8px；菜单/模态框 10–12px |
| 投影 | 非必要不加；浮层使用小范围柔和阴影 |
| 动画 | 120–180ms，尊重系统减少动画设置 |
| Focus ring | 清晰蓝色焦点圈，键盘可用 |

### 5.3 产品界面参照

参考：`brand/reference/UI_Preview_Reference_NOT_FINAL.png`

- 左侧：Workspace / Documents 文件树，选中文件有浅蓝底。
- 中间：多标签栏 + 清爽的 Markdown 页面，正文大块留白，标题清晰。
- 右侧：Outline 文档目录，未来可扩展 AI Chat 标签。
- 顶部：轻量窗口控制与工具操作，**不能**因参考图画有 Share / AI Chat 就把尚未实现的功能当作已上线。
- 设计应优先保留 Typora 式写作视野，不为贴合示意图牺牲编辑空间。

## 6. 浅色 / 深色模式

- 浅色：品牌原图优先，文档区白底或暖白底，字标深色。
- 深色：`#0B1220` 背景 + `#F8FAFC` 文本 + 蓝青点缀；对比度需检查。
- 图标可保留彩色 M / 折角结构，深色版水平字标反白。
- 不可仅通过 CSS `filter: invert(...)` 反色整张应用 Logo。

## 7. 资产规范与命名

**正式素材拟放路径**：`src/assets/brand/` 或 Tauri 项目规范允许的等效位置。参考图保存在 `brand/reference/`，两者不能混用。

```text
src/assets/brand/
  logo-horizontal-light.svg
  logo-horizontal-dark.svg
  logo-symbol.svg
  logo-symbol-mono-dark.svg
  logo-symbol-mono-light.svg
  app-icon-master.png          # 1024x1024 的正式图标母版
```

必须额外导出并检查：

- Tauri 需要的 macOS `.icns`、Windows `.ico`、各档 `.png` 图标。
- 透明底 Logo 在浅色、深色界面下的视觉效果。
- 16×16、24×24、32×32 尺寸的清晰可辨识度。
- Windows 高 DPI、macOS Dock、窗口标题栏和文件关联图标。

如果没有取得满意的独立矢量资产，**标记品牌图标交付未通过**，不要把参考图裁切伪装为正式源文件。

## 8. 禁止事项

1. 不要换用其他三版 Logo（山峰 M、绿色文档笔等均不是本次已选版）。
2. 不要改变 `MdStudio` 的大小写和品牌名称。
3. 不要把图标简化为纯 Markdown 字符 `M↓` 或普通文件图标。
4. 不要移除蓝色右上折角、右侧文本光标这两个识别细节（极小尺寸简化需单独审批）。
5. 不要把企业级仪表盘式 UI、生硬高饱和阴影当作主视觉。
6. 不要在正文大量使用淡紫、青色文字牺牲可读性。
7. 不要用完整品牌视觉板截图替代真实的 UI、图标或独立矢量 Logo。
8. 不要直接启用尚未实现的 AI Chat / 分享功能。
