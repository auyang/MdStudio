# MdStudio 品牌落地执行步骤与验收计划

> 任务代号：`BRAND-01`  
> 范围：将已选定的 MdStudio 视觉品牌真正接入 Rust + Tauri 2 + React / shadcn/ui 编辑器。  
> 停止条件：当前任务完成后状态设为 `awaiting_acceptance`，**不要擅自进入下一阶段**。

## 0. 使用前准备

1. 将整个 `mdstudio-brand-kit` 文件夹放到 MdStudio 项目根目录，或将 `docs/brand/*`、`brand/*` 复制至对应目录。
2. 保证 Codex 能访问 `brand/reference/MdStudio_Brand_Board_Approved.png` 原始参考图。
3. 在 MdStudio 工程根目录执行 Codex，并把 `docs/brand/CODEX_IMPLEMENTATION_PROMPT.md` 作为完整任务发给它。
4. 不要将参考图切块误认为可发布的成品素材；正式 Logo 需重绘/导出并经视觉验收。

## 1. 总体交付节奏

| 阶段 | 工作内容 | 交付物 | 门禁 |
| --- | --- | --- | --- |

## 2. B0 — 工程检查与基准锁定

**动作**

- 检查当前目录是否为 MdStudio 仓库；查明工程结构、Tauri 版本、CSS 主题结构、字体来源、logo/icon 资源路径。
- 如果项目已存在，**不得重建、覆盖已有项目或删除历史素材**；优先提交最小范围修改。
- 如果项目不存在，仅按既定 Rust + Tauri2 + React 架构初始化最小工程，然后执行品牌部分。
- 确认品牌参考路径和六个主色值；记录现有 UI 截图或当前页面结构。
- 建立 `docs/brand/BRAND_IMPLEMENTATION_REPORT.md` 并记录起始状态。

**验收**

- [ ] 没有误删未提交修改或源文件。
- [ ] 能指出现有 token、Logo、Tauri 应用标识配置入口。
- [ ] 原始视觉参考图存在且可读取。

## 3. B1 — Design Tokens 与主题

**动作**

1. 读取 `brand/tokens/mdstudio.tokens.json`。
2. 把品牌核心色、衍生无障碍操作色、字体、圆角、边框、面板尺寸接入项目现有 token 体系。
3. 优先复用 shadcn/ui 的 CSS 变量；不要建立第二套相互冲突的颜色系统。
4. 完成深色模式映射：字标反白，保持品牌蓝/青/淡紫的识别性。
5. 文档编辑区正文不要强制使用粗字重；保证中文和代码字体正常。

**验收**

- [ ] `#0F172A`、`#3B82F6`、`#06B6D4`、`#A78BFA`、`#E5E7EB`、`#F8FAFC` 正确落地。
- [ ] 亮/暗主题切换无闪屏、无不可读文本。
- [ ] 主要交互文字满足 WCAG AA 目标，品牌蓝不强行作为小字白色按钮底。

## 4. B2 — Logo 生产资产

**动作**

1. 使用参考图中的品牌标志作为几何参照，**保持原选定设计**：蓝青 M、文档纸张、右上蓝折角、右侧 I 型光标。
2. 优先输出标准 SVG；如无法精确复刻，明确标注复刻偏差并等待人工审查，不要声称“从图片提取到了原始矢量”。
3. 输出浅底水平组合、深底水平组合、独立符号、深浅单色符号。
4. 为图标准备 1024×1024 PNG 母版；用 Tauri 官方图标生成工具生成各平台资产。
5. 对比视觉板，以及 16、24、32、64、128、256px 实际效果。

**验收**

- [ ] M 的几何轮廓、文档折角、I 型光标均清晰。
- [ ] `MdStudio` 字标大小写正确，首选深色无衬线字标。
- [ ] SVG 不包含外链资源，具备稳定 viewBox。
- [ ] 文件独立可用，非整张参考板图片裁切贴图。
- [ ] 输出截图对照，指出所有不可避免的重绘差异。

**阻塞处理**：若没有可用矢量重绘条件，仍可完成 B1/B3，但 B2/B4 标记 `blocked`，不得使用截图裁切临时冒充正式 Logo。

## 5. B3 — 桌面编辑器 UI 品牌化

**动作**

- 以 `brand/reference/UI_Preview_Reference_NOT_FINAL.png` 为密度与风格参考。
- 顶栏使用 MdStudio 品牌标识；保留已有菜单与文件操作。
- 左侧文件树、中央标签栏/编辑区、右侧大纲采用轻量灰线、浅蓝选中态。
- Markdown 阅读排版宽约 820–900px、内边距合理；需要优先保护可编辑空间。
- 对所见即所得、源码模式、分栏模式分别检查。
- 减少卡片包裹、重阴影和高密度工具按钮；不要重设计 Milkdown、CodeMirror 的核心行为。
- 未实现的 AI Chat / Share 不可做成可点击假按钮；可隐藏或静态标为“规划中”，但不放在主编辑动线上。

**验收**

- [ ] 新建、打开、编辑、保存、另存为仍能正常使用。
- [ ] Milkdown + CodeMirror 切换无丢字/光标异常。
- [ ] 文件树、TOC、工具栏、标签符合选定视觉语言。
- [ ] 中文输入法、长表格、代码块、横向滚动与深色模式可用。
- [ ] 屏幕缩窄时边栏可折叠，正文不被截断。

## 6. B4 — 桌面图标和平台元数据

**动作**

- 修改 Tauri `productName` 为 `MdStudio`。
- 稳定应用标识 `identifier`，沿用已发布的标识；如果是新项目可合理创建并记录，不能随意更换造成升级问题。
- 用通过视觉检查的母版导出 `.icns`、`.ico`、PNG 图标资源。
- 检查 macOS Dock、Windows 标题栏、安装包、Linux 启动器图标。
- 若工程已有安装/更新签名流程，保留现有签名/升级机制，不擅自更换发布通道。

**验收**

- [ ] 主窗口标题和系统应用名一致。
- [ ] 图标在浅深背景下均可认出。
- [ ] `.icns` / `.ico` / PNG 非旧项目 Logo。
- [ ] 构建产物内不会出现参考板截图作为整屏背景。
