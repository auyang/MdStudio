### 已定位并验证的发票缺字根因

- `ofdrw-invoice.ofd` 的 `PublicRes.xml` 引用了楷体、宋体，但容器没有嵌入相应字体。无外部回退字体时，Engine 报 `W_FONT_MISSING` 并跳过 TextCode，Viewer UI 的文字搜索因此报告空文本。原始内容存在且正确，问题发生在字形资源解析阶段。
- POC 增加了手动加载本机 TTF/OTF/TTC 回退字体的控制，限制 32 MiB，仅内存使用，不复制字体、不随应用分发。macOS 选择 23.5 MiB `Hiragino Sans GB.ttc` 后，原始发票在 Viewer UI 与 Canvas 均能看到中文；查询发票代码 `050001700111` 返回 1 项。离线 Engine 脚本结果：无字体时 `itemCount=0`、`charCount=0`、2 个缺字体警告；传入该系统字体后 `itemCount=74`、`charCount=564`、0 个缺字体警告。
- 这是对该发票的可复现修复路径，不是通用默认字体方案：样本中声明的字体族和本机字体匹配策略、跨平台字体许可与安装情况尚未解决；字体缺少目标字形时也不能保证完整显示。

## P3 结论与安全边界

推荐 **C（暂缓 OFD 生产接入）**。现有实测只证明这两套 JS 实现能在当前 macOS WebView 打开一个公开的 1 页发票，并渲染部分非文字元素。不能推断票据、公文、印章、中文字形、加密和损坏文件兼容，也没有证明安全资源限制在恶意输入下有效。详细 Go/No-Go、风险策略及回滚范围见 POC_GO_NO_GO.md。

## 后续若进入实现：安全资源策略

以下是进入生产实现前必须采用并由恶意样本验证的初始上限，不代表本次已完成安全测试；超过上限应拒绝打开并给出简体中文错误，不能自动放宽。

| 威胁 | 必须实施的拦截策略 |
|---|---|
| 伪造扩展名/错误容器 | 扩展名只用于类型路由。验证 ZIP 签名/目录结构，并要求唯一、可解析的 `OFD.xml` 及有效 DocRoot；拒绝重复关键入口、冲突路径、截断目录和不支持的加密容器。 |
| ZIP bomb / 资源耗尽 | `OFDDocument.open` 显式传 `limits`：`maxPackageBytes=100 MiB`、`maxEntries=10,000`、`maxEntryBytes=32 MiB`、`maxTotalUncompressedBytes=256 MiB`、`maxCompressionRatio=100`、`maxXmlBytes=8 MiB`、`maxFontBytes=32 MiB`、`maxImagePixels=25,000,000`、`maxCanvasPixels=16,000,000`、`maxRecursionDepth=16`。这些比引擎默认更保守，先用合法大文件样本校准。也要校验 ZIP64 声明、重叠/重复条目与实际解压字节，不能只相信中央目录长度。 |
| 包内资源路径穿越 | 预检所有 archive entry 和 XML 引用；统一 `/` 分隔符；拒绝绝对路径、盘符/URI、NUL、空路径段歧义、`..` 越出根目录及规范化后重名；解析资源路径必须仍位于虚拟 OFD 根。绝不把包内路径拼接成宿主文件系统路径。 |
| XML 解析滥用 | 先按字节上限拒绝超大 XML；拒绝 DTD、外部实体和实体声明；为嵌套深度、节点总数、属性长度设限；解析失败只报当前文档错误，不能让其它标签崩溃。恶意 XML 与超时样本需加入兼容集。 |
| 巨大 Canvas | 在创建 Canvas 前检查宽、高、DPR、旋转后尺寸及像素乘积，应用 16 MP 单画布预算和每维 8,192 px 上限；一次只执行一个主视图页面渲染，邻近页分批，页面缓存默认最多 2 页。超限提示“页面尺寸过大，已停止渲染”。引擎当前默认 `maxCanvasPixels=0` 不设限，必须覆盖。 |
| 内存/标签关闭 | 记录并限制解压缓存、字体、图片和渲染缓存；关闭 tab 时先取消 render task、关闭 document/source，再释放 canvas 和监听器；异常路径同样执行幂等清理。性能验收需记录多个标签并存及关闭后的 JS heap/RSS。 |
| 卡死和超时 | Engine `signal` 是协作取消；不能证明它能中断主线程同步解析/绘制。生产前需验证 Dedicated Worker 隔离、超时后终止 Worker、canvas 结果转移（OffscreenCanvas/bitmap）及 Tauri WebView 覆盖。若无法中断，严格限制文件大小/解析复杂度并标明无硬超时保护，不对大文件开放。 |
| 网络访问 | 只接受 Tauri 已授权的本地字节源，不用远程 URL、CDN、远程字体或转换服务；CSP 的 `connect-src` 仅留必要 IPC，样本和依赖资源本地打包。 |

上表限额是待压测的初始配置建议，不是针对业务资料的最终容量承诺。Engine 的默认上限（包 256 MiB、条目 20,000、总解压 512 MiB、压缩比 200、XML 32 MiB、字体 64 MiB、图片 100 MP）来自本机安装包 `DEFAULT_RESOURCE_LIMITS` 类型；本 POC 没有对这些拒绝路径做攻击测试。
