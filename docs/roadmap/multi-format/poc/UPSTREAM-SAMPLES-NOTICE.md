# 上游样本许可提示

POC 样本取自 [OFDRW 仓库](https://github.com/ofdrw/ofdrw)。上游 README 声明仓库使用 MIT 许可，仓库根目录的 LICENSE 也为 MIT。样本由上游仓库公开提供，且 POC 记录了各文件的来源路径与 SHA-256。

但 OFD 容器内可能包含第三方字体、图像、商标或印章。仓库级软件许可不能证明这些内嵌素材均由仓库作者持有或获准再分发；其中 `发票监制章-数科.ofd` 的内容还带有 “For Evaluation Only” 字样。因此：

- 这些文件只用于本地兼容性 POC 和缺陷复现。
- 不把样本打入 MdStudio 正式安装包，不用于产品演示/宣传。
- 若要将样本提交到公开仓库或发布新的样本集，应先确认每个容器及其内嵌资源的权利，或换成自行生成且权属明确的合成样本。
- 样本读取不会修改样本；清单脚本只读检查 ZIP 和 XML 元数据。
