## 字体和图像

| ID | 验证项 | 状态 | 证据 / 未通过原因 |

| M-01 | OFD 内嵌字体优先 | 部分 | 引擎提供内嵌资源解析；无可授权嵌入字体样本验证不同格式和优先级。 |
| M-02 | macOS 系统字体回退 | 部分 | 字体数据库与目标字形匹配有 Rust 测试；本轮单发票实机列出 Hiragino Sans GB/PingFang SC/Courier New 候选且未发 `W_FONT_MISSING`。未证明所有字形均出现，也无第二份样本。 |
| M-03 | Windows 缺失字体回退 | 未测 | 无 Windows 构建/桌面环境。 |
| M-04 | 应用内 CJK 最终兜底 | 未实现 | 仓库和 bundle 没有思源 CJK 字体；系统字体设置只指向候选家族。 |
| M-05 | 特殊汉字/缺字续找 | 自动匹配部分覆盖，端到端未测 | `ttf-parser` 按 cmap 检查目标字符；没有特字 OFD 样本核对最终渲染。 |
| M-06 | TTF/OTF/TTC 容错 | 部分 | Rust 自动测试覆盖真实系统字体面、OTF、字体面解析错误和大小上限；没有其他 OS 的 TTC/字体集合实测。 |
| M-07 | PNG | 部分 | 本轮 macOS 发票的 `qr.png` 二维码可见；没有独立 PNG 裁剪、透明、变换样本。 |

| M-09 | JBIG2 | UI 集成未提供 | Engine 有 `ImageDecoderPlugin` 与 `W_JBIG2_DECODE`；UI React props 未公开 `imageDecoders` 注入。无 JBIG2 样本。 |
| M-10 | 不支持图片诊断 | 接口部分可用 | 引擎 `W_IMAGE_DECODE`、`W_JBIG2_DECODE` 会进入本轮诊断面板；没有真实文件触发截图。 |
