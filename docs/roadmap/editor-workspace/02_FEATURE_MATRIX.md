## P1 验收边界

- Markdown、PDF、OFD 文件均通过现有 `openDocuments` 进入既有 adapter/tab 流程。
- PDF/OFD 仅只读，不显示编辑或保存入口。
- 文件夹可不打开；原单文件选择、拖放、系统打开和最近文件路径不依赖工作区。
- Rust 端只返回目录条目元数据，不提供任意文件内容读取接口。
- 新建只创建空 Markdown 文件；已有目标必定失败，不覆盖。
- 不新增 npm/Cargo 依赖，不修改 `package.json`、lockfile 和版本号。
- 路线状态不改变 `docs/roadmap/multi-format` 中 P6-B 的 `blocked` 记录。
