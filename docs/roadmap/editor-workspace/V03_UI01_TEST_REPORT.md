- 左侧显示首页、最近、工作区、设置；侧栏收起为图标栏后可恢复。新偏好默认展开，宽度配置以 230px 为初始值。

- 未在本轮手工逐项切换浅色/深色/跟随系统主题，也未执行 Windows/Linux 桌面构建或实测。
- 最新代码的底部状态栏背景覆盖整个窗口宽度，包括左侧工作台；状态文字从窗口左侧统一留白开始排列。该 CSS 改动通过构建验证，未重新桌面截图核验。
